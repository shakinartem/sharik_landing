# ШАРиК digital

Сайт digital-агентства **ШАРиК digital** — маркетинг для стоматологий и клиник.

Строим системный digital-маркетинг: сайт, карты, репутация, контент, CRM, аналитика и автоматизация — чтобы пациент не терялся по пути к записи.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Preview собранного проекта

```bash
npm run preview
```
